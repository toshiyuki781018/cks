# 問題etc-1：bomを使用したコンテナイメージやバージョン情報を一覧化と削除

## 【問題】


```
この問題の最初見たときに全くわからなかったです。そもそもbomが何かもわからなかった
BOM は、Kubernetes クラスターで使用されている各コンポーネント
（kube-apiserver, kube-controller-manager, kube-scheduler, etcd など）
に関するコンテナイメージやバージョン情報を一覧化したものです
・クラスターの状態確認
・セキュリティ監査（どのイメージがどのバージョンか？）
・イメージのアップグレード計画

よって、この問題を解く選択肢は、BOMの使い方を覚えるか、そのまま暗記するかの2択の問題になります

対象のドキュメントが確認できるので、そのドキュメントを確認しつつ、問題を解く必要があります。
覚えておけば点数は取れますが、変更になった場合の対応ができないので、そこは注意。
```

# 問題etc-2：docker.socket＆docker.service

## ★解説
```
Linuxの基本コマンドとDockerの操作をある程度分かっていればできる問題
ただ、Dockerのドキュメントが見れない可能性もあるので、そうなると問題自体を覚えておいて回答を実施するしかない感じですね

docker関連の問題なので、覚えて臨むのが適切なのかなという感じです。
ただ、自身が問題を回答したときには、docker.sock & docker.serviceのファイル自体がなくってしまっていたので、そうなると
問題が解けない可能性がたかいです。
```

# 問題etc-3：Version-up-worker

## ★解説

```
改定前はControlplaneのバージョンアップ実施が必要名だったため、今より手順が多かったが
Workerノードのみのバージョンアップになったため、そこまで難しい問題ではないですね。

注意点としては、
apt-cache madison
apt-mark unhold 
apt-mark hold
```
上記3つのコマンドが必要になった点になりますので、そこは注意するようにしましょう。
```
